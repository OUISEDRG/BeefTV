## 任务恢复与维护

每个任务保存独立账本。提交前先持久化意图，提交回执不明时只查询专用分镜，不自动重提；已成功生成但下载失败时仅重取已有视频，不重新生成。支持 BeefTV 传入的 Idempotency-Key；没有键且内容重复的请求明确拒绝，避免将网络重试误当成新任务。

BeefTV 的视频轮询有等待期限（当前版本约 1 小时），新任务按5秒后台倒计时执行。即使画布等待超时，已提交任务仍由本机服务继续查询，完成后可在任务页取回视频。取消按钮仅用于尚未提交的本地任务。
