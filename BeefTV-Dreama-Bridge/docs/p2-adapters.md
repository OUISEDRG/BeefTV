# Dreama P2 适配器

`dreama_cli.py` 是 Bridge 和目录维护脚本的 CLI 传输入口。命令按 P1 合同分为读取、准备和收费。参数按 Dreama 1.0.5 help 校验，选项值封装成单独的 argv 项。Client 固定 prod 版本与端点，控制超时和环境，按退出码处理失败。能力目录独自请求原始信封，保留 `isExternal`、`vendorGroupCode` 和模型参数。

`dreama_video.py` 和 `dreama_image.py` 保持模型、绑定、提示词和结果回读规则。普通分镜创建和更新、积分报价、生成提交及任务状态均走 CLI。视频引用 HTML 超出 Windows 命令行上限时，发送前选择既有的兼容保存路径。保存后按同一规则回读原文与引用，CLI 写入失败时不切换传输重试。

`dreama_compat` 保留素材上传和素材库绑定、音色目录、延长、增强和独立音频。网站请求集中在固定端点的 `http.py`。媒体对象上传和字节校验在 `assets.py`，已有 CDN 下载规则继续用于交付。延长使用其原有原生分镜字段和历史对账，查询已确认任务时使用 CLI。增强和音频保留各自查询、匹配与状态转换。

`SubmissionService` 按 P1 账本先落库预算预留，再向当前调用提供一次发送资格。CLI 和兼容收费传输都核对任务、操作类型、Provider 快照及预留状态。发送资格只存于这次调用。重启从账本查询或对账，收费调用不随恢复而重放。收费传输没有自动重试，网络请求开始时 SQLite 写事务已结束。

P2 继续使用 P1 数据库格式和配置示例。读、准备、查询和交付使用独立路径。现有用户 API 与 Flow 模块入口保留，便于分支回滚及后续 BeefTV UI 接入。
