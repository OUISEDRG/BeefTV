# BeefTV 剧梦专用工作台实施计划

用户已经批准完整方案并要求实施。本文件是该方案的执行索引。

## Global Constraints

- 保留现有节点、资源、布局、连线、原文、音色和 Codex 推理设置；不新增收费试跑。
- 一张本地画布绑定一个剧梦项目，允许多个剧集分组；未分组节点使用明确默认剧集。已提交任务使用不可变快照。
- 仅开放已验证的 drama 项目及已经接通的图片、视频、延长、增强、配音；文本和助手沿用 Codex。
- Python 是外部提交、倒计时、远端对账的唯一执行器；Go/React 复用 BeefTV 任务和画布体系。未知提交不重提，下载失败不重新生成。
- 可视引用复用稳定引用编译；保持正文、换行、重复及顺序，最终素材与音色只映射一次。
- 新任务准备后 5 秒倒计时，报价变化重新倒计时，不加第二次确认。
- 插件、目录和画布修改通过正式接口；生产数据库不直接编辑；开发使用隔离数据。
- 官方稳定 tag 在隔离分支合入、回归、完整构建后安装，不直接用官方包覆盖定制 EXE。

## Tasks

1. 固化源代码、桥接和已安装程序基线，隔离工作树，保护凭据与真实数据。
2. Python：版本化绑定快照和迁移、持久准备队列、集成 API、动态能力与项目/剧集路由。
3. React 参数：动态图片分辨率、音频能力、生成/增强/延长操作与真实限制。
4. React 工作台：项目与多剧集绑定、可视引用快照、内嵌任务、正式目录刷新入口。
5. Go：已保存渠道凭据支持的受控集成门面、目录 CAS 更新、隐藏服务启动及接口文档。
6. 发布：上游检查/隔离集成/构建/安装/回退脚本、版本清单、回归与本机验收。

## Acceptance

多集不串任务；目录新变体和 3K 无需写模型名判断；无效参数零提交；重排/重复/角色展开引用与音色不串位；重启/取消竞争/未知回执不重交；旧数据保留；Codex 能力回归；升级和回退维护任务账本事实。离线回归、真实只读和实际 Take 观察分别记录，未进行的验收不可写成通过。
